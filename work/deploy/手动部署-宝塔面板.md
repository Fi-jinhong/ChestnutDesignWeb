# 栗子作品集部署手册（腾讯云 + 宝塔面板）

目标：把静态作品集站点部署到 **chestnut.hi.cn**（124.223.104.141），替换现有 WordPress。

---

## 第 0 步：确认信息

- 域名：chestnut.hi.cn（已解析到 124.223.104.141，www 也已解析）
- 现有站点：WordPress（宝塔面板管理）
- 站点压缩包：`outputs/chestnut-site.zip`（176M，含 index.html、projects/、media/、downloads/ 等）

---

## 第 1 步：备份现有 WordPress（先做，别跳过）

**1.1 备份数据库**（最容易漏的一步）
宝塔面板 → **数据库** → 找到 WordPress 对应的库 → 点「备份」→ 备份完成后点「下载」存到本地。

**1.2 备份网站文件**
宝塔面板 → **文件** → 进入站点根目录（通常是 `/www/wwwroot/chestnut.hi.cn`）→
在最外层文件夹上右键「压缩」→ 生成 backup.zip 留在服务器上即可。

如果不想压缩（185M 归档慢），也可以在终端把目录改名留档：
```bash
mv /www/wwwroot/chestnut.hi.cn /www/wwwroot/chestnut.hi.cn.wp-backup
mkdir -p /www/wwwroot/chestnut.hi.cn
```

---

## 第 2 步：上传站点压缩包

推荐用**腾讯云控制台的 WebShell**（实例 → 登录），工具栏有「上传文件」，直接把
`chestnut-site.zip` 传到 `/root/`（宝塔文件管理器上传有大小限制，176M 大概率超限）。

> 若上传中断，可先在本机分卷再逐个上传：
> ```bash
> split -b 50m outputs/chestnut-site.zip chestnut-site.zip.part-
> ```
> 服务器上合并：
> ```bash
> cat chestnut-site.zip.part-* > chestnut-site.zip
> ```

---

## 第 3 步：解压到站点根目录

在 WebShell 或宝塔「终端」里执行（把路径换成你实际的站点根目录）：

```bash
WEBROOT=/www/wwwroot/chestnut.hi.cn
mkdir -p $WEBROOT
unzip -o /root/chestnut-site.zip -d $WEBROOT
ls -lh $WEBROOT
```

确认能看到 `index.html`、`projects/`、`media/`、`downloads/`、`assets/`、`local/`。

---

## 第 4 步：替换 Nginx 站点配置

宝塔面板 → **网站** → chestnut.hi.cn → **设置** → **配置文件**，
把 `work/deploy/nginx-bt.conf` 的全文粘贴替换进去（里面的 root 路径改成你实际的站点根目录）。

关键变化：去掉了 WordPress 的 PHP 转发规则，加了静态资源缓存、gzip、目录式 URL 兜底。

保存后宝塔会自动重载 Nginx；若没生效，点「服务」→ Nginx「重载配置」。

---

## 第 5 步：验证

浏览器打开 http://chestnut.hi.cn/ ，确认：
- 首页正常、背景视频能播放（Safari 也 OK，Nginx 原生支持 Range 请求）
- `/projects/nuannuan` 等项目详情页能打开
- 简历 PDF 能下载

---

## 第 6 步：开 HTTPS（强烈建议）

1. **腾讯云控制台 → 安全组 → 放行 443 端口**（当前 443 未开放，SSL 会申请失败）
2. 宝塔面板 → 网站 → 设置 → **SSL** → 选 **Let's Encrypt** → 点「申请」→ 勾选域名 → 申请
3. 打开右上「强制 HTTPS」
4. 宝塔会自动加定时任务续期，不用管

---

## 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 打开还是 WordPress | 站点根目录没换对，或浏览器缓存；强制刷新 Ctrl+Shift+R |
| 首页 404 | 配置文件里 root 路径填错，或 index 没设为 index.html |
| 项目详情页 404 | 配置里缺 `try_files` 兜底，用我给的 nginx-bt.conf |
| 上传 zip 失败 | 用腾讯云 WebShell 上传，或按第 2 步分卷 |
| SSL 申请失败 | 443 端口没放行 / 域名解析未生效 |
