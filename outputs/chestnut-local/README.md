# 作品集本地站点

这是作品集网站的本地静态版本，可离线运行，无需任何依赖安装。

## 启动

```bash
npm start
```

然后打开 <http://127.0.0.1:4173/>。

## 内容

- 主页：Hero、关于我、精选项目（2 个）、过往项目（3 个）、联系方式
- 5 个项目详情页：暖暖拾光、么么直播、来嗨 3.0、么么直播 9 周年盛典、其它运营设计
- 站内图片、人像形象照、微信二维码、简历 PDF 与作品集 PDF 分片

## 结构

```
server.mjs       # 零依赖静态文件服务器
public/          # 站点全部静态资源
```

站点主色 `#A886FF`，样式微调集中在 `public/local/local-overrides.css`。
